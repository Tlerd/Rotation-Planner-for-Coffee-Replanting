    Slope and erosion risk

    The default slope (1.7 %) is computed from SRTM 30 m elevation around the demo farm (data/srtm_demo.json). SRTM cannot be fetched live from this static page, so for other locations set the slope by hand. Live SRTM lookup for any point is future work. Heavy-rain month = 200 mm of rain or more (team assumption). Erosion index = slope % × heavy-rain months; below 20 is low, 20–60 medium, 60 or more high (team assumption). A higher index gives the erosion-control priority more weight.

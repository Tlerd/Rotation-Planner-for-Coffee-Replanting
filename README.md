# ReRoot – Rotation Planner for Coffee Replanting

NASA Space Apps Challenge 2026 · Challenge: **Field Shift: Adapting Farms with NASA Data**

ReRoot helps smallholder coffee farmers on sloped land plan the 2–3 year rotation between removing old coffee trees and replanting.

**Live app:** https://tlerd.github.io/Rotation-Planner-for-Coffee-Replanting/

## Status
- [x] Milestone 1 – Load 10-year monthly climate (rain, temperature, root-zone soil wetness) for any farm from NASA POWER
- [ ] Milestone 2 – Rotation crop scoring by farmer priorities
- [ ] Milestone 3 – Slope / erosion risk from SRTM

## NASA data
- NASA POWER (Agroclimatology, monthly point API): PRECTOTCORR, T2M, GWETROOT – https://power.larc.nasa.gov/
